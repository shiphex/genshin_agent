来源：`rag/eval/questions_dev.json`（版本 0.5）。从110题中不放回随机抽取，按抽取顺序分为四批；以下参考答案照录题库，尚未经过本次第三方核验。

## 第1批

### gq2-077

**题目：** 《深海龙蜥实验记录》如何区分进化观察、研究者的「种子」猜想和水龙王人形预言？它能否单凭实验直接确认后来某个角色的身份？

**参考答案：** 记录描述龙蜥子代在不同环境下出现耐寒或耐热特征，研究者随即说结论尚不足，只可印证「种子」觉醒与母体编制的猜想。另一段又记智力学习实验，并引述水之龙王将以人形诞生的预言。观察、猜想和预言层级不同，这份实验本身没有点名后来的人形水龙王。

### gq2-057

**题目：** 丝柯克为何把神之心称作「第三降临者的遗骨」？这段转述对于第三降临者的姓名、死期及神之心材质确认到了什么程度？

**参考答案：** 丝柯克先说那维莱特身上带着「第三降临者的遗骨」，再用地面常说的「神之心」对应它。她承认师父没有告诉她第三降临者是谁、何时死去；那维莱特也以「如果没有误会或特殊比喻」和「如果她说的真实」保留条件。因此这段不能给出姓名、死期，或把「遗骨」的字面材质当成独立核验的事实。

### gq2-008

**题目：** 《匪石》中昆钧怎样区分若陀个人的记忆变化与“我们”的群体磨损？他如何把层岩巨渊之战归给“你”，又怎样解释“我们／你／我”的关系？再对照钟离的磨损自述，不能把什么症状混为一谈？

**参考答案：** 昆钧说磨损使若陀想不起故友面貌和璃月港；谈到共处能力与理性时改称“我们”，并说“我们”成为“你”、再从“你”意志分出“我”。他把层岩巨渊之战归给“你”，这是昆钧对白中的解释。钟离称亲手封印老友也是自身磨损；角色故事5写熟悉的一切消逝、职责自问，未说他同样失忆或失理性。

### gq2-079

**题目：** 「博士」声称降临者应有特殊位阶，与纳西妲关于旅行者越过世界树屏障的解释，分别属于哪类说法？能否据此证明博士许诺的「特权」已落实？

**参考答案：** 博士以旅行者寿命与来历不同为由，许诺让「生来就是降临者」的旅行者回到所谓应有位阶，这是他的劝诱主张。纳西妲另以世界树没有旅行者记录解释他／她为何不被屏障阻挡。后者说明一次具体作用，不证实博士的价值判断或许诺已经兑现。

### gq2-045

**题目：** 凝光处理重大商业事务时会去哪里，谁负责整理资料？

**参考答案：** 她去群玉阁，只让三名心腹陪侍；心腹翻阅资料、整合文书并把摘要贴在墙上，凝光据此思考方案。

## 第2批

### gq2-024

**题目：** 诺艾尔目前在骑士团做什么？她希望将来成为什么？

**参考答案：** 诺艾尔目前是骑士团女仆，边训练学习边帮助蒙德居民；她盼望有朝一日通过骑士选拔，穿上骑士甲胄。材料没有说她已经成为正式骑士。

### gq2-041

**题目：** 白术、七七和长生在不卜庐的相处怎样体现照料与熟悉？「白先生」称呼又是如何传开的？

**参考答案：** 七七最初记不住白术与长生的名字，白术耐心找回外出忘归的她，还给她准备笔记。七七后来叫他「白先生」，来问药的客人把称呼传遍璃月港。另一段日常故事写白术、长生、七七在不卜庐一同生活，白术还在夜里教七七做柔软体操；这些是照料与相处的叙述，不需推断血缘关系。

### gq2-069

**题目：** 尼可为何希望奈芙尔重新看待自己的恨意？奈芙尔接受了哪些判断，又拒绝了什么？

**参考答案：** 尼可以天使引导真实愿望的职责为由，希望听奈芙尔过去；她认为记忆和情感依托现实中的人、场景与事物，若须弥毁灭，奈芙尔珍视的记忆也可能随之淡去。奈芙尔承认自己不只有恨，却拒绝尼可替她改变想法，并说自己希望记住那些旧情感。尼可的心理推演不能写成奈芙尔已被说服。

### gq2-107

**题目：** 《日月前事》称旧世界有七位龙之大王，尼可另说三月由尼伯龙根令其升起。两处各描述龙族旧时代的哪一面？能否仅凭它们列出七王姓名？

**参考答案：** 古籍描述原初王座与七位龙之大王开战；尼可讲述尼伯龙根令三月升起、月神代其管理世界。两处分别涉及战争对手和统治安排，都没有给出七位龙王的完整姓名名单，也不能单凭这两处把尼伯龙根定为名单中的某一位。

### gq2-036

**题目：** 《逐影猎人》怎样叙述这一职名的由来与逐影庭后来的工作变化？阿兰·吉约丹曾造出会思考的机械这一说法，在同一套故事中处于什么证据层级？

**参考答案：** 生之花说，被称为「黄金猎人」的卡西奥多协助建立「逐影猎人」一职；文本同时提醒，真正的妖魔罕见，被贬作妖魔的人常有。后来逐影庭更专注犯罪调查而非战斗，并大量吸收美露莘。死之羽另把阿兰造出能思考的机械写作传说：说法来自共事者，缺少实物，也未进入官方记载；这不能直接当成已证实的技术史。

## 第3批

### gq2-067

**题目：** 按《日月前事》的纪年，第二王座到来后海渊先祖为何落入黑暗？书中怎样推断后来第一王座与第二王座的胜负，为什么不能把推断当目击记录？

**参考答案：** 古籍写葬火之年第二王座到来、天地崩裂，海渊先祖和土地坠入此处，黑暗年代开始。日月二年先祖寻归途时见到第一王座布下禁令，书中据此说第一王座「应该」打败了第二位；这只是作者依据禁令作的推断，不是战争现场的直接记录。

### gq2-016

**题目：** 温迪为什么选择设法救助特瓦林？他最初打算怎样帮助它？

**参考答案：** 温迪说自己的理由是「自由」：曾守护蒙德的龙也应有选择生活方式的权利，不该被欺骗说城市背叛了它，也不该被要求永远守护城市。他最初打算借助天空之琴，从噩梦中唤回特瓦林的本性。

### gq2-039

**题目：** 琴和芭芭拉是什么关系？童年时父母分开后，她们分别跟随谁？

**参考答案：** 琴与芭芭拉是姐妹。父母分开后，年幼的琴跟随母亲芙蕾德莉卡，芭芭拉跟随父亲西蒙·佩奇；后来芭芭拉也同父亲一样加入西风教会。

### gq2-040

**题目：** 神里绫人与绫华怎样分担社奉行和神里家的事务？两人的角色故事分别强调了什么？

**参考答案：** 绫人的故事说，社奉行事务繁重，妹妹绫华分担家族事务并负责社奉行与民间的大部分交流，绫人因此更能专注政务。绫华的故事说，兄长政务忙且不爱抛头露面，兄妹商定由她在公众场合维护家族形象、与伙伴和贵族周旋，同时掌理家中事务。两份材料相互补充，不能说绫华只管社交或绫人不参与家族事务。

### gq2-050

**题目：** 夜神说，她在被称为「夜神」之前属于什么存在？退化后的形态又被冒险家称作什么？

**参考答案：** 夜神说过去这一类存在名为「天使」；退化之后，冒险家更熟悉的称呼是「仙灵」。

## 第4批

### gq2-080

**题目：** 世界树在天理到来前是否已经存在？阿佩普与纳西妲分别怎样叙述其古今用途和后来的变化？

**参考答案：** 阿佩普说世界树在天理之前已有，龙族时代的作用与样貌不同，后来被天理夺走、改造以供人类使用。纳西妲也说世界树早于天理；在另一段对白中，她称天理将光界力化分为元素力，把世界树改造成记录装置，并为其严重危机定下隔绝须弥的规则。世界树先存与后来改造是不同阶段；「夺走」体现阿佩普的敌对立场，不能当成两人共同使用的评价。

### gq2-023

**题目：** 琴为何代行西风骑士团团长职责？故事中大团长法尔伽去了哪里？

**参考答案：** 法尔伽仍是西风骑士团的大团长；故事称他半年前率领骑士团精锐离开蒙德远征，把骑士团交给琴，因此琴代行团长职责。

### gq2-011

**题目：** 在与纳西妲相见时，大慈树王怎样说明两者与世界树的关系？她为何要求纳西妲抹除自己？主线结尾又由谁提出了什么记忆疑问？

**参考答案：** 大慈树王在意识空间自述自己是世界树的化身，纳西妲是她折下的最纯净枝杈。她说自己与世界树相连，因此也受禁忌知识污染；即使死去，相关存在仍会留在树中，妨碍根除污染，所以安排纳西妲抹除自己。之后纳西妲说污染已被清除，旅行者的内心旁白则疑问派蒙是否也忘记了大慈树王。

### gq2-030

**题目：** 赛诺追捕的违令学者陷入险境时，他为何还要营救？《大恶人》中的冒险描写又该如何看待？

**参考答案：** 赛诺救人是为了把违令者安全带回教令院受审；他解释只有教令能审判对方，自己的职责是将人交予教令。获救学者后来写了小说《大恶人》，但赛诺明确说其中赤王后裔魔物、活体迷宫和虫腹避风等经历被夸张描写，不能当成实际追捕过程。

### gq2-096

**题目：** 流浪者怎样解释亥珀波瑞亚虚影所述历史与尼可记忆的差异？按他的说明，多托雷又怎样借「伪月」让通往月亮的门把哥伦比娅送到自己身边？

**参考答案：** 流浪者说，他让虚影与尼可对质后发现两边的历史不同：虚影的叙述多出一个许诺造新月、带回月神的「救世主」，并向其透露了月亮知识。他指认多托雷在背后操纵，但也说多托雷没有亲自进入那扇门；按他转述的尼可解释，同时代虚影之间的因果联系受干扰，巨大的变数使未见过多托雷的虚影也受影响。流浪者接着说，多托雷把变数化为知识，造出令术法误判位置的「伪月」；门通过月矩力定位月亮，当伪月比天外霜月更像月亮，就把哥伦比娅送到多托雷身边。后来多托雷控制她并夺走两块月髓。上述追查和机制保留流浪者转述的来源。
