## 尚未解决的模型问题

- **不确定性被抹掉（q07）**：l12 原文说葬身之地“很可能”位于地中之盐；模型把“葬身之地位于……”列为确定事实。找到完整证据并不保证保留原文的确定性程度。
- **引用 ID 正确但归属错误（q08）**：模型将“精通衣冠日用、珠玉瓷器”和“事事都很讲究”归到 l04，实际在 l03。两段都已检索到，但引用支持检查仍失败。
- **指代过度解释（q06）**：《尘世之锁》原文没有写出少女姓名；回答仍引入“少女/旅行者”等不受该片段支持的身份说法。它也回答“没有直接写名字”，但这不抵消前面的无依据补充。
- **无关记忆插入（q02）**：正确主答案之外，模型额外提到资料未涉及的托马。不能只看主要事实正确就判为完全遵守证据限制。
- **引用格式不稳定**：q03、q04、q06、q10 使用 `[片段 ID: l11]` 一类非约定格式。标准格式识别不能为这些输出判断引用支持关系，需要人工检查。严格解析到的 ID 未出现上下文外 ID，也不代表其他错误不存在。
- **拒答仍可带无依据背景（q11）**：虽然正确拒绝回答数值，附带解释却把石锁背景说成若陀龙王相关，原文未提供这种对应。拒答成功不是整段回答无幻觉。
