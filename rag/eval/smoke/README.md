## 执行与输入

模型为 Qwen3.5-4B Q4_K_M，llama.cpp b9837、RTX4060/Vulkan0、8192上下文，关闭思考和上下文移位。Top5、温度0、seed42、输出预算1536；模型与服务哈希、实际参数、源码身份见[catalog](../../catalog.json)的smoke记录，不将当前源码冒充当时版本。

[questions.jsonl](questions.jsonl)逐行提取旧12题输入的前三题，内容和顺序不变。旧运行通过limit=3选择它们；旧完整输入哈希与新文件指纹分别登记，原执行文件已淘汰。

## 结果与依据

| results.jsonl | 三题完整Top5证据、六份原始回答及调用信息 |

## 复用与限制

默认检索与模型对照使用本页三题，命令见[模块说明](../../README.md#语料与检索)。普通验证使用retrieval-only，不启动服务、不调用模型。真实对照必须已有本地服务，会写新输出。

旧运行ID、旧路径及旧测试数量若仍在原件中出现，只表示历史元数据。预检、分词、GPU观测、旧保护清单及重复报告已按用户决定淘汰；基线不宣称保留完整运行环境或全部执行证据。
