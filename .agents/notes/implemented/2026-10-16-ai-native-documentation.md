# Agent Note: 中文 AI-native 文档体系

Status: implemented

## 问题

项目已有文档分工，但根 context 与模块重复记录实现及实验状态，根 README 有搬移前断链，缺少统一分类模板与中文字数门禁。新会话需要按任务找到事实，而不把历史结论、候选方案或技术完成误作当前验收。

## 决策

采用 DeepSeek Harness 的职责分层：根 AGENTS 维护长期约束，项目 context 导航阶段；docs 维护架构、开发流程、文档规范和术语；模块 README 维护接口与命令，模块 context 维护问题与最近验证。实验、发布和历史材料仍在原位置，当前与历史的含义分别标明。

三个独立 skill 使用通用名称 doc、prose-standard、agent-experience，分别处理组织与核验、文字含义、上下文加载。七类中文模板由 doc 维护，类型映射在文档规范；必要英文术语保留。Agent Notes 只记录重要决策，状态目录按需建立；普通小改动无需记录。

预算由显式 manifest 维护，Python 标准库检查汉字及 ASCII 连续词，并拒绝超限、缺失或非法配置；只读展示与验收退出码区分。脚本不改正文或自动提高上限。命令与计数约定分别由[开发流程](../../../docs/development.md#验证)和[文档规范](../../../docs/AGENTS.md#字数门禁)维护。

## 考虑过的替代方案

**仅新增导航和一个整合 skill**：最初的最小方案维护成本更低，但用户明确选择现行文档适配、独立 skill、模板与预算，不采用该方案。

**完整复制上游工具链**：上游双语、网站、插件模板、Notes 分类与归档门禁不适用于当前范围，采用职责和核验机制即可，避免引入无对应运行能力的命令和依赖。

**直接按空白分词计数**：中文正文会少计，选择混合计数；它是文档预算单位，不是模型 token 测量。

## 影响

常规文档包含摘要与页内目录，极短文件夹索引及指令格式豁免。RAG context 原正文保留为历史区，因此预算较高；以后不再追加过程流水账。模板符合性、链接和术语本轮实际审查，暂不建设通用解析门禁、CI 或 hooks。

新体系只改变文档与项目级检查，不改变 RAG 行为、数据、题库、配置或用户验收状态。审阅入口是可维护文档，其发布 manifest 只同步该页大小与哈希；历史实验来源、案例、旧 ZIP 和源码版本不变。

## 验证

2026-10-16：预算检查器的 4 项行为测试经历缺实现失败与实现后通过，覆盖混排、代码、链接、临界值、超限、非法配置、缺失与只读行为；既有 101 项 RAG 测试、catalog 检查、30 案例／96 份回答精确摘录检查通过。28 个预算项通过并保留约 5% 以上余量。链接和编码检查覆盖本轮现行页面、模板说明及既有跟踪文档，未发现断链或损坏；代码块内模板占位链接不作为真实链接检查。

两个独立只读会话分别验证原规则和显式加载三个 skill 后的相同场景，均能避免复制全部模块命令、丢失失败保护及为小修重跑实验；另实际对照 overview 模板和根 README。基线未观察到上述错误，不宣称新 skill 已证明降低错误率或 token 成本。随后明确路由先读模块 context 当前区，历史按需回查。

保护检查覆盖 11,792 个既有文件，其中 11,780 个未授权修改的文件哈希不变；仅本轮 12 份可维护文档／元数据变化，RAG context 原历史正文完整保留，暂存区不变。原始数据、既有结果、题库、RAG 实现及测试、配置、catalog 和原开发题 skill 均未修改。

独立只读最终审阅检查了实际差异、检查器与测试、三个 skill、模板及 Notes，未发现需修复问题；审阅者实跑预算、预算测试、差异和精确摘录检查。客户端自动发现、外链与 ZIP 恢复不在该审阅的已验证范围。
