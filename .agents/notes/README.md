# Agent Notes

## 摘要

Agent Note 保存实现和普通文档不能充分解释的重要决策原因、替代选择和代价。跨模块职责、对外行为、数据兼容或有持续价值的技术取舍需要记录；局部修字、链接、机械改动不需要。当前行为仍由架构、模块文档与实现维护。

## 状态与位置

文件为 `<状态>/YYYY-MM-DD-topic.md`，目录按需创建，不另加分类子树。日期是首次提出日期，不随完成改名。

| 状态 | 内容 |
| --- | --- |
| proposed | 尚未完整实施的方案、备选项、验收要求和风险 |
| implemented | 已实现决策、取舍、影响及真实验证，正文描述已落地状态 |
| rejected | 保留原方案和否决原因，防止重复讨论 |

使用 [Agent Note 模板](../skills/doc/templates/agent-note.md)。状态改变时同步路径、`Status:` 和章节，并修复入链；不能只改标签。新的不同决策另写记录并互相链接，不把旧记录改成相反决定。不为每次小改动增写记录；没有新的长期取舍时维护已有记录即可。
